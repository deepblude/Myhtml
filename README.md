# 写给她的圣诞节网页 🎄

这是去年圣诞节，我写给自己暗恋的女孩子的一个 HTML 网页。

最后虽然没有成功，但还是想把它分享出来，希望能帮到大家。也祝你们能把心意传达给喜欢的人。✨

## 使用方式

下载项目后，用浏览器打开 `index.html` 就可以查看。请将 `music.mp3` 与网页放在同一个目录下，以便正常播放背景音乐。

你可以修改网页中的文字、效果和音乐，写下属于自己的心意。

## 部署到 Netlify，分享给心上人

如果想把网页做成一个有网址、可以直接访问的网站，可以部署到 [Netlify](https://www.netlify.com/)。这样就不用把文件发给对方，只要分享一个 URL，就能把这份心意送给自己的心上人。

- 下载项目并解压，按自己的想法修改文字和音乐。
- 注册或登录 Netlify，打开 [Netlify Drop](https://app.netlify.com/drop)。
- 将包含 `index.html` 和 `music.mp3` 的项目文件夹拖入上传区域，确保 `index.html` 位于上传文件夹的根目录。
- 部署完成后，Netlify 会提供一个可以公开访问的 HTTPS 网址，例如 `https://你的站点名.netlify.app`。
- 用手机打开网址，确认页面和音乐正常，再把链接分享给心上人。背景音乐可能需要点击页面后才会播放。

Netlify 提供的免费子域名就可以直接使用，不需要另外购买域名。如果你已经有自己的域名，也可以在站点的域名管理中绑定，并按提示配置 DNS。
