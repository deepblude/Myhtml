Conda 是什么？给零基础的 10 分钟上手课

一句话：Conda 是“Python 环境管理 + 包管理”工具，帮你把不同项目的依赖隔离开，避免互相打架。

先理解概念

为什么你需要 Conda

  • 不同项目可能要不同版本的 Python（3.9 / 3.10 / 3.11）。
  • 同一个库（如 numpy）版本不同会冲突。
  • Conda 可以给每个项目一个“独立小房间”（环境）。
  • 你删掉一个环境，不会影响其他项目。
最推荐

安装哪个：Anaconda 还是 Miniconda

  • Miniconda（推荐新手）：轻量，只装最核心组件。
  • Anaconda：很全，但大，初学阶段经常装一堆用不到的包。
  • 首次学习建议先装 Miniconda，后续需要什么再装什么。
实操命令

5 条最常用命令（先会这几个就够了）

# 1) 新建环境（例：Python 3.9）
conda create -n myenv python=3.9 -y

# 2) 进入环境
conda activate myenv

# 3) 在当前环境安装包
conda install numpy
# 或者：pip install 包名

# 4) 看当前环境装了什么
conda list

# 5) 退出环境
conda deactivate
重点：看到命令行前缀从 (base) 变成 (myenv)，就说明你已经进入该环境。
避坑

新手最容易踩的坑

  • 忘记先 conda activate 环境名 就安装包。
  • 在 base 环境里乱装所有项目依赖。
  • 同一环境里混装冲突版本，导致运行报错。
  • 没确认版本匹配（你刚才 MindSpore 就是这个问题）。
跟你场景相关

你这次为什么建议先 `conda create`

  1. 你的 base 里已经有旧的 MindSpore 相关包。
  2. 直接在 base 里改，容易残留旧依赖。
  3. 新建环境可以“从干净状态”安装匹配版本。
  4. 如果失败，删环境重来即可，不影响别的项目。
# 建议流程（示例）
conda create -n ms271_py39 python=3.9 -y
conda activate ms271_py39
source /usr/local/Ascend/ascend-toolkit/set_env.sh
pip install mindspore==2.7.1
python -c "import mindspore; mindspore.set_context(device_target='Ascend'); mindspore.run_check()"
